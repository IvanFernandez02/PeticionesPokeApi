📚 Información de la Práctica

🎯 Objetivo

Comprender y aplicar conceptos de HTTP/HTTPS, métodos REST, códigos de estado y CORS consumiendo datos reales de Pokémon.

⚡ API Utilizada

PokéAPI: API REST pública con información completa sobre Pokémon, habilidades, tipos, movimientos y más.

URL: pokeapi.co

Documentación: pokeapi.co/docs/v2

📊 Códigos de Estado

  • 200: OK - Petición exitosa
  • 201: Created - Recurso creado exitosamente
  • 400: Bad Request - Error en la petición
  • 404: Not Found - Recurso no encontrado
  • 500: Internal Server Error - Error del servidor

🔍 Herramientas de Análisis

Abre las Developer Tools (F12) y revisa:

  • Console: Logs detallados de cada petición
  • Network: Headers, tiempos de respuesta, CORS
